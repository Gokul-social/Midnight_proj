# Managed — Compiled ZK Circuit Artifacts

This directory contains the binary circuit artifacts produced by the Midnight Compact compiler (`compactc v0.31.1`).

**Compile command:**
```bash
compactc compile contract/src/zk_expense_splitter.compact managed
```

---

## Directory Layout

```
managed/
├── zk_expense_splitter/
│   ├── keys/          ← Real binary proving & verification keys (committed)
│   ├── contract/      ← Generated TypeScript/CommonJS SDK bindings
│   └── witnesses/     ← Witness interface module
├── zkir/              ← ZK intermediate representation (human-readable + binary)
└── compiler/
    └── contract-info.json  ← Compiler metadata (circuits, ledger schema, witnesses)
```

## ZK Intermediate Representation (`zkir/`)

The `zkir/` directory contains human-readable (`.zkir` JSON) and binary (`.bzkir`) circuit
intermediate representations, also generated by `compactc`. These are inspectable without
the Midnight toolchain:

```bash
cat managed/zkir/initialize_group.zkir | head -30
```

---

## Prerequisites for Re-compilation

If you need to regenerate these artifacts from source:

1. Install the Midnight toolchain: https://docs.midnight.network/develop/tutorial/building/
2. Ensure `compactc` is in your PATH
3. Run: `npm run compile`

The `npm run compile` script runs:
```
compactc compile contract/src/zk_expense_splitter.compact managed
```
